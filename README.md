# HonghuaEatsBetelNut

這個專案提供一個以 `info.jpg` 氛圍為基礎的 Python 小遊戲 Demo：

- 第一階段：劇情選擇文字遊戲（多分支、多結局）
- 第二階段：解謎元素（古書、羽毛筆、檳榔盒密碼鎖）

## 執行方式

1. 確認使用 Python 3（內建 tkinter）
2. 在專案根目錄執行：

```bash
python game.py
```

## 遊戲簡介

你需要在圖書館場景中蒐集 3 個線索，推理出檳榔盒密碼，取得「安魂符」後再面對紅花。

- 蒐集完整線索並成功解鎖：真結局
- 蒐集部分線索直接面對：普通結局
- 準備不足或解鎖失敗耗盡次數：壞結局
