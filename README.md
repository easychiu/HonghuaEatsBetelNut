# HonghuaEatsBetelNut — 深夜完全版

以 `info.jpg` 哥德式暗黑美學為基礎的視覺小說遊戲 Demo，深化版新增：

- 動態場景插圖（基於 info.jpg 風格，Pillow 生成）
- Mureka.ai 背景配樂自動生成與播放
- 豐富的多分支劇情與典故系統
- 兩種謎題類型與 5 種結局

## 安裝依賴

```bash
pip install Pillow pygame requests
```

> 若無上述依賴，遊戲仍可以純文字模式執行（無圖像、無音樂）。

## 執行方式

1. 確認使用 Python 3.10+（內建 tkinter）
2. 在專案根目錄執行：

```bash
python game.py
```

## 遊戲簡介

你是深夜闖入廢棄圖書館的調查員。銀髮少女紅花正在咀嚼檳榔，她說：  
「紅花綻放之處，便是你的葬身之地。」

你必須在天亮前蒐集線索、破解謎題，找到拯救她——或逃離她——的方式。

### 可探索場景

| 場景 | 說明 |
|------|------|
| 圖書館大廳 | 主要調查區域，含古書・羽毛筆・檳榔盒 |
| 書架深處 | 四書排序謎題，解開可得地下室鑰匙 |
| 研究桌 | 紅花的日記，揭露詛咒真相 |
| 窗邊 | 雨水打濕的紙條，感受紅花的孤獨 |
| 地下室 | 封印典籍，解鎖「秘密結局」的關鍵 |

### 謎題

1. **密碼鎖**：從三個線索推算三位數密碼 → 取得「安魂符」
2. **書架排序**：按時間順序排列四本古書 → 取得「書架鑰匙」

### 結局

| 結局 | 達成條件 |
|------|---------|
| 秘密結局 | 安魂符 + 全部 3 個典故（日記・窗邊・地下室）|
| 真結局 | 安魂符，對紅花使用 |
| 普通結局 | 蒐集 2 個以上線索後直接面對 |
| 壞結局 A | 毫無準備就面對紅花 |
| 壞結局 B | 密碼盒輸錯三次 |

### 配樂

遊戲啟動後會自動透過 Mureka.ai API 在背景生成哥德式管弦樂 BGM，  
生成完成後自動播放。BGM 檔案快取於 `assets/bgm_main.mp3`。
